# UART Sensor Module Configuration Examples

## Production Configuration (prj.conf additions)

```kconfig
# UART Sensor Module Configuration
CONFIG_APP_UART_SENSOR=y

# Basic Communication Settings
CONFIG_APP_UART_SENSOR_RX_BUFFER_SIZE=512
CONFIG_APP_UART_SENSOR_LINE_BUFFER_SIZE=256
CONFIG_APP_UART_SENSOR_MSG_QUEUE_SIZE=20
CONFIG_APP_UART_SENSOR_ZBUS_TIMEOUT_MS=2000

# Threading and Performance
CONFIG_APP_UART_SENSOR_THREAD_STACK_SIZE=3072
CONFIG_APP_UART_SENSOR_THREAD_PRIORITY=4
CONFIG_APP_UART_SENSOR_PROCESSING_TIMEOUT_MS=10000

# Data Validation (Production Recommended)
CONFIG_APP_UART_SENSOR_DATA_VALIDATION=y
CONFIG_APP_UART_SENSOR_TEMP_MIN=-40
CONFIG_APP_UART_SENSOR_TEMP_MAX=85
CONFIG_APP_UART_SENSOR_HUMIDITY_MIN=0
CONFIG_APP_UART_SENSOR_HUMIDITY_MAX=100
CONFIG_APP_UART_SENSOR_REJECT_INVALID_DATA=n

# Error Handling and Recovery
CONFIG_APP_UART_SENSOR_ERROR_RECOVERY=y
CONFIG_APP_UART_SENSOR_MAX_CONSECUTIVE_ERRORS=3
CONFIG_APP_UART_SENSOR_RECOVERY_DELAY_MS=10000
CONFIG_APP_UART_SENSOR_STATISTICS=y

# Probe ID Configuration (No Formatting)
CONFIG_APP_UART_SENSOR_PROBE_ID_FORMAT=n
CONFIG_APP_UART_SENSOR_PROBE_ID_MIN_LEN=3
CONFIG_APP_UART_SENSOR_PROBE_ID_MAX_LEN=31
CONFIG_APP_UART_SENSOR_DEFAULT_PROBE_ID="UNKNOWN_PROBE"

# Protocol Settings
CONFIG_APP_UART_SENSOR_MESSAGE_DELIMITER="\r\n"
CONFIG_APP_UART_SENSOR_FIELD_SEPARATOR=":"
CONFIG_APP_UART_SENSOR_VALUE_SEPARATOR=","

# ZBUS and Publishing
CONFIG_APP_UART_SENSOR_AUTO_PUBLISH=y
CONFIG_APP_UART_SENSOR_TIMESTAMP=y

# Power Management
CONFIG_APP_UART_SENSOR_POWER_MANAGEMENT=y
CONFIG_APP_UART_SENSOR_DEVICE_SETTLE_DELAY_MS=50

# Logging (for debugging)
CONFIG_APP_UART_SENSOR_LOG_LEVEL_INF=y
```

```kconfig

CONFIG_APP_UART_SENSOR_RX_BUFFER_SIZE=1024

# High thread priority

# Fast timeouts
CONFIG_APP_UART_SENSOR_PROCESSING_TIMEOUT_MS=1000
CONFIG_APP_UART_SENSOR_ZBUS_TIMEOUT_MS=500

# Minimal settling delay
CONFIG_APP_UART_SENSOR_DEVICE_SETTLE_DELAY_MS=5

# Optional: Only publish on significant changes
CONFIG_APP_UART_SENSOR_PUBLISH_ON_CHANGE=y
CONFIG_APP_UART_SENSOR_CHANGE_THRESHOLD_TEMP=2  # 0.2°C

# Keep statistics for monitoring performance
CONFIG_APP_UART_SENSOR_STATISTICS=y

# No probe ID formatting for performance
CONFIG_APP_UART_SENSOR_PROBE_ID_FORMAT=n
```

## Device Tree Configuration

Add to your device tree overlay (e.g., `nrf9160dk_nrf9160_ns.overlay`):

```dts
&uart1 {
    status = "okay";
    current-speed = <115200>;
    tx-pin = <29>;
    rx-pin = <28>;
    rts-pin = <27>;
    cts-pin = <26>;
    hw-flow-control;  /* Optional: if using flow control */
};
```

For custom UART device node:

```dts
/ {
    aliases {
        uart-sensor = &uart1;
    };
};

&uart1 {
    status = "okay";
    current-speed = <115200>;
    tx-pin = <29>;
    rx-pin = <28>;
    
    /* Optional: Configure for low power */
    /delete-property/ hw-flow-control;
};
```

Then set in Kconfig:
```kconfig
CONFIG_APP_UART_SENSOR_DEVICE_NODE="uart1"
```
